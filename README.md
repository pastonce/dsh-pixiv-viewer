# dsh-pixiv-viewer

DeepSeek Harness 的 Pixiv 看图插件：左侧栏入口、缩略图浏览、每日推荐、搜索 / 标签筛选、我的收藏、R18 开关、大图查看、保存与账号同步收藏。

## 功能

- 左侧菜单栏一键入口，进入独立的缩略图列表页
- 未搜索、未选分类时默认显示随机「每日推荐」（取当日排行榜随机打乱），可一键刷新；搜索框清空后同样回到每日推荐
- 底部栏左侧始终提示当前结果来源（如「「女の子」的搜索结果」「分类：原神」或「每日推荐」）
- 搜索划分为四类：标签 / 作品名 / 作者ID / PID（作品 ID）；类型下拉框与输入框、搜索按钮连成一体，操作提示内嵌在输入框占位文本中
- 搜索只在按回车或点击「搜索」时触发：切换类型、点选预设标签、输入过程都不会自动发起请求；切换热度档位、翻页会立即重新检索
- 搜索结果支持分页（上一页 / 下一页，每页最多 80 条 = 10 行 × 8 张，无丢页）
- 标签搜索支持集合运算：`|` 并集、`+` 或空格 交集、`-` 排除；运算符必须独立成词（前后各有一个空格），紧贴在词上的符号视为标签名的一部分（如 `R-18`、`C++` 不会被误判）
- 标签搜索预设区固定展示 399 个标签（三行横向滑动，399 = 3 的倍数、每列恰好 3 个）：其中 300 个从 posts > 20000 的热门标签中随机抽取，另 99 个来自「我的收藏」作品的标签（不足时从热门池补足）；排除热度档位类标签（如「原神1000users入り」）、按中文词义去重（「原神」与「Genshin Impact」只留一条）、按作品数从大到小排列；列表只在重新打开插件页面时刷新，每个标签悬停显示对应中文名；点击预设后标签末尾自动补空格、焦点回到输入框，便于继续输入运算符
- R18 相关标签受 R18 开关控制：开关关闭时，预设标签与输入联想中都不出现明确露骨标签（如 R-18、巨乳、中出し、全裸），收藏统计预设区同样过滤；打开开关后恢复显示（水着、内衣、ブルマ 等边缘标签不受影响）
- 输入联想自动匹配中文同义词（如「百合」→ yuri），联想列表每行右侧显示对应中文，支持 ↑/↓ 选择、空格 / 回车填入
- 内置 4.3 万条 pixiv 标签中文对照（数据来自 [ffdkj/Pixiv_Tag-Chinese-English-Translation-Table](https://github.com/ffdkj/Pixiv_Tag-Chinese-English-Translation-Table)，MIT，筛选 posts ≥ 1000，按热度排序）：查看器与收藏统计里的任意标签悬停可显示中文译名；输入框联想支持直接输入中文译名匹配到原标签（如输入「东方」→ 東方）
- 热度档位筛选：`100users入り` / `500users入り` / `1000users入り` / `3000users入り` / `5000users入り` / `10000users入り`，切换后立即按当前关键词 / 分类重新检索；标签 / 作品名 / 作者ID 搜索均支持
- 「最新 / 最旧 / 热门」排序，切换后立即按当前输入文本重新检索（每日推荐不受排序与档位影响，两个下拉框禁用）；在筛选结果内二次过滤（标题 / 标签 / 画师），筛选框可收起
- R18 开关（关闭 = 过滤掉 R18 作品；开启 = R18 与普通作品混合显示）、隐藏 AI 作品开关
- 预置分类：原神、崩坏：星穹铁道、绝区零、未定事件簿（支持分页与热度档位；选中分类后进行搜索仍在该分类内检索，标签 / 作品名类型有效）
- 自动过滤视频 / 动图（ugoira）作品
- 点击缩略图查看大图（左上角显示 PID、标题居中；多页作品翻页时先隐藏旧图再加载新页，键盘 ←/→ 或 A/D 翻页、Esc 关闭、加载失败可重试）
- 查看大图时滚轮以鼠标位置为中心放大（最高 8 倍）、放大后可按住拖动平移视角
- 查看器内可「复制图片」到剪贴板（在「保存图片」按钮左侧），也支持保存图片到本地
- 查看器左上角点击作者名（带作者 ID）→ 快速查看该作者的全部作品；下方标签条显示全部标签，放不下时支持鼠标滚轮 / 横向拖动左右滚动
- 缩略图右下角悬停显示下载 / 复制按钮（下载自动取原图尺寸）；缩略图左下角显示 R18 / AI 角标，两者可同时出现
- 缩略图加载失败时可在该图上单独重试
- 收藏 / 取消收藏，与 pixiv 账号数据实时同步；收藏与取消收藏、下载、复制图片均有成功 / 失败提示，复制期间持续显示「正在复制图片」、下载期间持续显示「正在下载图片」，结束后弹出对应结果提示；多个提示竖向堆叠显示、互不遮挡
- 已收藏作品的缩略图右上角红色爱心常驻显示（未收藏时悬停才显示）
- 「我的收藏」：上方栏一键进入，分页拉取全部已收藏作品（底部栏显示加载进度），支持与普通搜索完全相同的检索与筛选——标签（含集合运算）/ 作品名 / 作者ID / PID 本地检索、热度档位、R18 / 隐藏 AI、最新 / 最旧 / 热门排序、分类词过滤、80 条每页分页，全部在本地内存完成、不产生额外 pixiv 请求；可直接在列表里取消收藏
- 「我的收藏」页的预设标签区变为收藏标签统计：统计所有收藏作品的标签频数，按数量从大到小排列（三行横向滑动），每个标签单元为「标签 × 频数」，悬停显示中文，点击仍进入搜索框
- 结果缓存：相同的搜索 / 分类 / 详情在 5 分钟内直接复用（收藏变更时自动失效），重复操作不再反复请求；图片走浏览器长缓存（7 天）；收藏列表按官方分页方式（48 条/页）逐页读取并缓存 5 分钟，重复进入立即命中

## 安装

```bash
dsh plugin add github:<你的用户名>/dsh-pixiv-viewer
```

本地目录安装：

```bash
dsh plugin add <插件目录绝对路径>
```

安装后需在 profile 的 `dsh.profile.bundles` 中确认 `dsh-pixiv-viewer` 已启用（`dsh plugin add` 会自动写入）。

## 登录（一次即可）

插件完全复用 pixiv 网页版接口，你只需粘贴一次浏览器里的会话 Cookie，不接触账号密码：

1. 浏览器中登录 https://www.pixiv.net/
2. 按 F12 → 「应用 / Application」标签 → 存储 → Cookie → https://www.pixiv.net → 复制 `PHPSESSID` 的值
3. 插件面板 → 「登录 pixiv」→ 粘贴 PHPSESSID → 「保存并登录」

插件会用这个 Cookie 验证登录并读取你的用户名；之后搜索、R18、热门排序、收藏同步全部走它。

Cookie 仅保存在本机 `~/.pixiv-viewer/`，不会被记录到日志。

> 注：PHPSESSID 与账号强相关，请勿泄露给他人。失效（登录状态过期）时在设置里重新粘贴即可。

## R18、排序与搜索说明

- **R18 开关**：关闭时只请求普通作品（过滤掉 R18）；开启时 R18 与普通作品混合显示。走网页版接口，登录后即可使用，未登录时打开开关会自动弹出登录提示。
- **排序**：「最新」与「最旧」均有效；「热门」与 pixiv 官网当前的搜索结果排序行为一致（pixiv 后端目前对 `popular_d` 返回与最新相同的顺序，官网「人気順」页也是如此）。「最受喜爱 / 最多浏览」没有对应的关键词搜索接口，故未提供；想浏览按人气排序的内容可用默认的「每日推荐」。切换排序会立即按当前输入框中的文本重新请求一次。
- **每日推荐**：使用 pixiv 的 `/ajax/top/illust` 当日排行榜，随机打乱后展示，点「刷新」重新抽取。每日推荐没有排序与档位概念，此时「最新 / 最旧 / 热门」与热度档位下拉框处于禁用状态。
- **搜索类型**：
  - 标签：pixiv 标签部分匹配；支持集合运算（`|` 并集、`+` 或空格 交集、`-` 排除），可与热度档位组合（如 `女の子 空 - 雪` + `1000users入り`）；`|` `-` `+` 需前后各有一个空格独立成词才被识别为运算符，紧贴词尾的符号按标签名的一部分处理（如 `R-18`）
  - 作品名：按标题 / 说明文字搜索（`s_tc`）
  - 作者ID：输入作者的用户 ID（数字）；或直接点击任意作品查看器左上角的作者名自动搜索。pixiv 网页版已下线「按名字搜索作者」的功能，故无法只凭名字搜索
  - PID：输入作品 ID，直接打开该作品
- **热度档位**：`xxxx users入り` 档位（如 `1000users入り`）按标签**包含**档位文本来筛选——pixiv 官方的 `1000users入り` 标签与同人里程碑标签（如「原神1000users入り」）都会命中；搜索结果本身带收藏数的场景（作者ID 搜索、我的收藏）则直接按实际收藏数 ≥ 阈值过滤。档位筛选走普通标签搜索 + 本地标签检查，**零逐作品详情请求**，不会触发 pixiv 限流（搜索请求携带的标签列表是完整的）；隐藏 AI 通过服务端 `-AI生成` 排除加本地 `AI生成` 标签兜底。档位标签由 pixiv 在作品收藏数过线时自动添加、其后不会移除，因此个别收藏数后来跌破阈值的作品仍会保留在档位里——与 pixiv 官方档位页的展示完全一致。
- **预置分类**：对分类下的每个关键词逐页取结果、按作品去重合并（如「崩坏：星穹铁道」同时搜中日文两个词）；选中分类后，标签 / 作品名搜索会把分类词作为交集条件附加进去，PID / 作者ID 搜索则自动退出分类。分类与简单标签搜索支持分页（每页 80 条）。
- **加载速度**：搜索结果（1 分钟）、作品详情（5 分钟）在宿主端缓存，重复操作直接命中缓存、不再经过 1.5s 限速器；图片走 pximg CDN 时不携带账号 Cookie，限速放宽（120ms 间隔、并发 ≤ 6），浏览器端缓存 7 天（由浏览器磁盘缓存管理），宿主端另有 48MB / 30 分钟的内存缓存（查看大图后立即下载 / 复制图片免二次拉取）；查看器按原始方式加载（大图从上到下渐进显示），并预加载多页作品的下一页与列表中下一张作品的首图。所有内存缓存都有硬上限（48MB / 固定条目数）与 TTL，且每 5 分钟主动清扫过期条目，不会无限堆积。

## 代理

国内网络环境需要代理。插件设置中配置代理地址（如 `http://127.0.0.1:7890`），留空则回退到 `HTTPS_PROXY` / `https_proxy` / `HTTP_PROXY` / `http_proxy` 环境变量。

## 账号安全说明

针对封号风险，插件内置了以下约束：

- 所有网页接口请求串行化，间隔 ≥ 1.5 秒；「我的收藏」按官方网页自身的分页方式逐页读取（48 条/页，5 分钟缓存），作者作品列表同样按 48 条/批分批读取（最多 200 条，1 分钟缓存），不做任何批量扫描
- 图片请求走 pximg CDN 且不携带账号 Cookie（仅 Referer + UA），独立限速（120ms 间隔、并发 ≤ 6）；重复内容由短 TTL 缓存与浏览器长缓存吸收，避免反复请求
- 只使用你自己的 `PHPSESSID` 会话，本地存储、绝不输出日志
- 收藏写入复用网页版自身的 CSRF 令牌，仅在需要时刷新
- 不做 HTML 抓取、不做批量操作

尽管如此，插件并非 pixiv 官方客户端，任何第三方客户端的使用都存在账号风险，请自行斟酌。

## 开发

```bash
npm run check   # node --check 全部 lib 文件
```

结构：`lib/index.js`（宿主端，注入 HTTP 路由）、`lib/routes.js`（REST 接口）、`lib/pixiv.js`（pixiv API 客户端）、`lib/client.js`（浏览器端 UI）。

### 更新标签对照表

对照表数据每日更新，重新生成（需要 Node ≥ 22.13）：

```bash
# 先 clone / pull 数据仓库（含 16MB tag.sqlite）
git clone https://github.com/ffdkj/Pixiv_Tag-Chinese-English-Translation-Table.git pixiv-tag-table
# 生成并写入 lib/client.js（默认阈值 posts >= 1000；可改，如 3000 / 5000）
node scripts/build-extratags.mjs pixiv-tag-table/tag.sqlite 1000
```

也可直接把 URL 传给脚本（自动下载，走 `HTTPS_PROXY` 代理）。生成后运行 `npm run check` 并重启 DSH。
